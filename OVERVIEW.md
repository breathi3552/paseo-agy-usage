# Antigravity Usage

View Antigravity CLI (`agy`) quota remaining and reset times in Paseo. Requires Paseo >= 0.11.0 and a local `agy` login; Linux also requires `secret-tool` and an unlocked system keyring, and finds the keyring from headless hosts (systemd service, container) through `XDG_RUNTIME_DIR` or `/run/user/<uid>`.
