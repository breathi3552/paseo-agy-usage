# 无桌面 Linux 会话接入与本地凭据文件回退

在无桌面 Linux 环境中，后台服务常因缺少会话总线环境变量而无法访问系统密钥环。有时命令行工具在无会话总线时把新令牌写进了本地回退凭据文件，系统密钥环里却还留着旧的过期令牌。

插件在 Linux 下会先从 `XDG_RUNTIME_DIR` 或 `/run/user/<uid>` 推导并接入常驻的用户会话总线，优先从系统密钥环读取令牌。只有当系统密钥环无法访问、为空或所含令牌已过期时，插件才会读取本地回退凭据文件，并在文件令牌未过期时采用文件令牌。

## 备选方案

- **在宿主配置中新增独立的文件存储类型**。回退凭据文件只是命令行工具在系统密钥环失败时的本地备份，对外暴露独立类型会破坏宿主按操作系统归属账号的约定。
- **只要系统密钥环非空就始终采用密钥环令牌**。当命令行工具降级更新了本地回退凭据文件却无法清理系统密钥环时，始终采用密钥环会导致插件一直读到已过期的旧令牌。
